# Gst_calculator

# 🇮🇳 GST Calculator (India)

A simple and beautiful **GST Calculator** built with **Python Flask**. This web app allows users to calculate Goods and Services Tax (GST) based on a given amount and GST percentage. Ideal for Indian users and small businesses.

---

## 🔧 Features

- Input amount and GST rate
- Automatically calculates GST and total payable amount
- Responsive, attractive UI using HTML and CSS
- Built with Python Flask
